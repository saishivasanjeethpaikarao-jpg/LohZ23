# Installation

Development: `npm install`, then `npm run dev`.

Desktop development: `npm run desktop:dev`.

Windows installer: `npm run package:win` creates an NSIS installer in `release/`. Linux `.deb` and macOS `.dmg` commands are configured, but must be built and tested on their native release hosts. Public releases require signing/notarization credentials and `LOHZ_SIGNED_RELEASE=true`.
